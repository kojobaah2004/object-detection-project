 Object Detection Project

 Description
This project builds an object detection and recognition model trained on a custom dataset of personal images. The images are annotated with bounding boxes and used to train a model with Ultralytics YOLO.

Objective
To detect and recognise a person in images using a custom-labelled dataset.

## Tools and Technologies
- Python
- Ultralytics (YOLO)
- Google Drive (image storage)
- Git and GitHub (version control)
- Ollama with Llama 3.2 1B (local language model)

## Dataset
- Source: Personal photos taken by the author
- Variations: different angles, lighting, backgrounds, and accessories
- Format: JPG images, annotated with bounding boxes
- Folder structure: `raw_images/`, `annotated/`, `dataset/`
